# ORBITAL

THE GAME
--------
ORBITAL is a space exploration game where you pilot a small rocket through
three dangerous sectors. Collect every energy core, manage your fuel, use
planetary gravity to navigate, avoid crashing, and reach the exit gate to
make it home.

CONTROLS
--------
WASD / Arrow Keys  - Thrust and steer
Enter / Space      - Start, continue to the next sector, or retry
M                  - Pause or resume the music
S                  - Open settings from the title screen
Escape             - Restart the current sector during gameplay
Escape in menus    - Back out of settings/credits; quit from the title screen
Mouse              - Select menu buttons
